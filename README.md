# AIAteMyRAM

A single-page crisis tracker documenting the 2024–2026 global RAM shortage driven by AI demand.

Inspired by the iconic [linuxatemyram.com](https://www.linuxatemyram.com/).

**Live site:** https://jains99.github.io/aiatemyram/

## What it covers

- DRAM prices up 171% YoY — how AI broke the memory market
- DDR5 spot prices quadrupled since September 2025
- Global inventory collapsed to 2–4 weeks of supply
- Timeline of events from 2022 to present
- Impact across PCs, smartphones, cloud, gaming, and automotive
- Links to primary sources: Bloomberg, IDC, BISI, IEEE Spectrum

## Built with

Plain HTML/CSS — no dependencies, no build step.
